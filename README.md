# Task Manager App

A simple, clean task manager I built with Flutter as part of a live class assignment. You can add tasks, tick them off when they're done, delete the ones you don't need, and keep an eye on how much is still pending, all in one tidy screen.

## Technology

- Flutter
- Dart
- Provider (for state management)

## Download APK

Want to try it out? Grab the latest Android build from the
[GitHub Releases](https://github.com/raju-bd/task-manager-app-release/releases)
page.

## Installation

1. Open the [Releases page](https://github.com/raju-bd/task-manager-app-release/releases).
2. Download `app-release.apk` from the latest release.
3. Open the downloaded APK on your Android phone.
4. If Android asks, allow installation from this source (it's a one-time permission).
5. Tap Install, then launch the app and start adding tasks.
